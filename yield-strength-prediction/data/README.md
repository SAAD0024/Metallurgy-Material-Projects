# Data

The raw steel database used in the analysis is intentionally not committed to this repository.

The notebook expects the source workbook at:

```text
data/raw/Steel database with labelled clusters.xlsx
```

The analysis reduced 3,234 raw records to 1,943 unique records after cleaning and deduplication.

If redistribution rights for the source dataset are available, the raw workbook can be added locally without changing the analysis workflow.
